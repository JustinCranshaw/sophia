# Supplied logo SVGs

The three `sophia-original-*.svg` / `sophia-originals-overview.svg` files are unchanged archive members from the user-supplied `files.zip`.

- Passage uses the standalone mono path in the comparison contexts. Its color and mono originals are also shown directly.
- `sophia-supplied-cove.svg` and `sophia-supplied-soft-six.svg` extract the first light-placement path group labeled Cove / Soft six in the original overview. Path data and all geometry/paint attributes are unchanged. The overview's card placement transform is not part of the glyph.
- Context symbols retain those exact path data, stroke widths and joins. Only `fill` / `stroke` paint maps to `currentColor`, and a uniform scale of 0.16 maps the 200-unit source viewport to the existing 32-unit viewport. Every rendered size uses the same imported geometry; there are no optical small-size cuts.
- These are supplied assets, not new concepts authored by the earlier design charrette. No ownership, novelty or trademark-clearance claim is made.

Safety inspection before rendering found only static SVG geometry/text/metadata and local clipping references; no scripts, events, external references, embedded images, foreign content or stylesheets. The comparison uses local asset URLs only.
